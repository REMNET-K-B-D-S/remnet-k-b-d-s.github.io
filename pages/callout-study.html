06ASCII ZINE

ASCIIでは、注意文が「手作業」になる。

画像も角丸も使わず、記号と空白だけで境界を描く。

+----------------------------------------------------------+
| [!] IMPORTANT / REMNET NOTICE                           |
+----------------------------------------------------------+
| このプログラムは、画面に表示された情報を読み取るだけです。 |
| 予期しない動作が起こらないとは限りません。                 |
| 内容を確認し、自己責任でご利用ください。                    |
+----------------------------------------------------------+
| STATUS: READ BEFORE USE / ANSWER: YOURS                 |
+----------------------------------------------------------+
REPRODUCE / コードを見る
<pre class="ascii-notice">
+------------------------------+
| [!] IMPORTANT                |
+------------------------------+
| ここに注意文を入れます。       |
+------------------------------+
</pre>

.ascii-notice {
  white-space: pre-wrap;
  font-family: monospace;
}

観察結果：文章は同じ。でも、役割が違って見える。

命令、会話、住所、記録、掲示、手作業。文章を囲う形が変わると、読む人が想像する「誰が・なぜ作ったのか」まで変わる。

結論：角丸を消せば人間製、ではない。

どのデザインもAIで生成できるし、人間も作れる。「AIっぽさ」を完全に消す方法ではなく、見慣れた組み合わせを一度ほどき、別の理由で組み直すための実験です。

好きなのを自分で選べ・参考にしてな。
