# REMNET_K_B_D_S


REMNET_K_B_D_Sという個人が運営する、思考・記録・文献・制作のデジタルアーカイブです。

- サイト：https://remnet-k-b-d-s.github.io/
- リポジトリ：https://github.com/REMNET-K-B-D-S/remnet-k-b-d-s.github.io

## このサイトについて

日記、調査や出来事の記録、テーマについての記事、文献への参照、制作した作品を整理して公開します。
本人が公開する範囲を選び、完成したものだけでなく、考えや制作の過程も残します。
大学・研究機関などの公式見解や、査読済みの研究成果を示すサイトではありません。

企画・構成・文章・公開内容の判断はREMNET_K_B_D_Sが行い、
ChatGPTやCodexを文章の整理・デザイン・HTML制作の補助に活用しています。

## 主な機能

- 分類と一覧からのページ移動、タイトル・本文・タグの検索
- 複数タブ、PCでのタブ並べ替え、比較表示
- 左右のパネル幅の調整、分類の折りたたみ
- プロパティ付きの日記、コールアウト
- 本文のデザインと表示設定の切替

ライトモードも暗めの配色にしているのは、意図したデザインです。
利用できる操作や設定の保存は、端末・ブラウザの条件によって異なります。

## 構成と公開用ビルド

- index.html：サイトの入口
- pages/：本文のページ
- assets/：表示設定・操作・検索データ・画像
- works/：作品と各作品のライセンス
- scripts/update-policy.ps1：方針のMarkdownからHP用ページを更新
- scripts/update-search.ps1：ページ登録と検索データの更新・検査
- build.ps1：公開するファイルの出力
- .github/workflows/pages.yml：GitHub Pagesへの公開処理

PowerShell 7で次を実行すると、方針ページをMarkdownから生成し、検索データを更新・検査して、公開ファイルを_siteへ出力します。

~~~powershell
pwsh -File ./build.ps1
~~~

既存の出力先は上書きしません。新しい通常ページはpages直下へ置き、
固有のdata-page、title、新規登録時のremnet-groupを指定します。
必要ならremnet-tagsでタグを指定します。
日記原稿の編集・変換は、管理用の更新手順に従って行います。
研究・取材方針はルートのサイトポリシー_研究・取材に関する方針.mdを編集してください。生成先のpages/site-policy.htmlは直接編集せず、ビルドで更新します。README.mdもpages/readme.htmlへ自動変換され、左側の「案内」から読めます。

原稿、下書き、私的通信、制作管理、検査用コピーを、公開サイトへまとめて入れる運用にはしていません。
GitHubへの送信が公開処理につながるため、変更内容と送信対象を確認してから反映します。
