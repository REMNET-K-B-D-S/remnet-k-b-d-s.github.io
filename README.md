# REMNET_K_B_D_S


REMNET_K_B_D_Sという個人が運営する、思考・記録・文献・制作のデジタルアーカイブです。

- サイト：https://remnet-k-b-d-s.github.io/
- リポジトリ：https://github.com/REMNET-K-B-D-S/remnet-k-b-d-s.github.io

## このサイトについて

日記、調査や出来事の記録、テーマについての記事、文献への参照、制作した作品を整理して公開します。
本人が公開する範囲を選び、完成したものだけでなく、考えや制作の過程も残します。
大学・研究機関などの公式見解や、査読済みの研究成果を示すサイトではありません。

企画・構成・文章・公開内容の判断はREMNET_K_B_D_Sが行い、
ChatGPTやCodexを文章の整理・デザイン・HTML制作の補助に活用しています。

## 主な機能

- 分類と一覧からのページ移動、タイトル・本文・タグの検索
- 複数タブ、PCでのタブ並べ替え、比較表示
- 左右のパネル幅の調整、分類の折りたたみ
- プロパティ付きの日記、コールアウト
- 本文のデザインと表示設定の切替

ライトモードも暗めの配色にしているのは、意図したデザインです。
利用できる操作や設定の保存は、端末・ブラウザの条件によって異なります。

## 構成と更新方法

| 場所 | 入っているもの |
|---|---|
| site/index.html | 左の一覧・タブ・本文を表示するHPの枠 |
| site/案内 | ホーム、REMNETについて、README・方針の表示 |
| site/日記 | 日記一覧と、Markdownから作る日記ページ |
| site/記録、site/記事 | 記録・記事の一覧と本文 |
| site/文献・問い | 文献、問い、タグから探すページ |
| site/制作 | 制作の案内、作品の紹介、コールアウトの説明 |
| site/つながり、site/連絡先 | 活動先・販売の案内と連絡先 |
| site/作品 | 元のデザインで動く作品本体・説明資料・ライセンス |
| site/共通 | 見た目、操作、検索データ、日記画像 |
| tools | 公開用ファイルの生成、検索更新、保存場所と公開URLの対応 |
| .github/workflows/pages.yml | GitHub Pagesへの公開処理 |

日記の文章はMarkdownの原稿を編集し、PCの日記準備処理からHTMLと画像を作ります。生成された日記HTMLや検索データを直接編集する運用ではありません。
このリポジトリには日記の下書き・私的資料・Obsidian保管庫を入れません。原稿の準備から公開するまでの道具は、PC側で別に管理しています。

READMEの原稿はルートのREADME.mdです。
研究・取材方針の原稿はsite/案内/サイトポリシー_研究・取材に関する方針.mdです。
対応するreadme.htmlとsite-policy.htmlは公開用ビルドで更新します。

PowerShell 7で次を実行すると、方針ページと検索登録を更新・検査し、公開用ファイルを_siteへ出力します。

~~~powershell
pwsh -File ./tools/build.ps1
~~~

既存の出力先は上書きしません。保存するフォルダと公開URLはtools/公開先.jsonとパス.ps1で対応させています。
これにより、日記や作品を役割別の場所へ整理しても、現在の正式URL・本文ページ・画像URLは維持します。
新しい通常ページは該当する分類の中へ置き、固有のdata-pageとtitle、remnet-groupを指定します。必要ならremnet-tagsでタグを指定します。

以前の入口へ案内するだけだった旧構成（ルートの古いHTML、About、Links、日記公開基盤、SPIRIT表紙_試作05）は、公開対象から外しました。現在のサイトの入口は https://remnet-k-b-d-s.github.io/ です。

GitHubへの送信は公開処理につながるため、実際に送る変更と公開用の出力を確認してから反映します。
